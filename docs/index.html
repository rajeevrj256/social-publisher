Aesthetic Finds Publisher

A private tool that publishes my own short-form videos to my own YouTube channel on a schedule.

What it does

  • Reads short videos from my own media library.
  • Proposes each one to me for approval, with a title and description, over a private Telegram chat.
  • Uploads only what I personally approve to my own YouTube channel, at a scheduled time.

Who it is for

Me. It is a single-operator tool for my own channel and is not offered as a service to anyone else.

YouTube access

It uses the YouTube Data API v3 to upload videos to the channel that authorised it. It does not read, modify or delete any other content.
